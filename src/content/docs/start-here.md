This playbook follows one robot, Robot A, from the kickoff video to working code. It is written so that you can do the same thing yourself on a new game.

:::note[Under construction]
The site is live but the chapters are still being written. They fill in once Robot A's CAD and code are finished.
:::

## How every chapter is laid out

Each chapter has the same four parts, so you always know where to look.

1. **What we decided.** The outcome, in a few sentences and a picture.
2. **Why.** The options that were on the table and what tipped the choice.
3. **The math.** A worked example with Robot A's real numbers, then a calculator for your own numbers.
4. **Your turn.** The steps to do this for a new game, as a checklist.

## How sure are we?

Robot A has not been built yet. Every result in the playbook carries one of three labels:

- **Calculated:** worked out on paper or in a spreadsheet.
- **Simulated:** run in the robot simulator.
- **Tested:** measured on real parts.

## How Robot A was made

Robot A is a practice design for REEFSCAPE, the 2025 FIRST Robotics Competition game. A Team 4206 mentor designed and coded it in the off-season, working with Claude, an AI model made by Anthropic.
