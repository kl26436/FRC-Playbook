This playbook follows one robot from the kickoff video to working code. It is written so that you can do the same thing yourself on a new game.

:::note[Under construction]
The first chapters are up as drafts. The rest fill in as the CAD and code are finished.
:::

## How every chapter is laid out

Each chapter has the same four parts, so you always know where to look. A part is left out where it would only repeat another.

1. **What we decided.** The outcome, in a few sentences and a picture.
2. **Why.** The options that were on the table and what tipped the choice.
3. **The math.** A worked example with the robot's real numbers, then a calculator for your own numbers.
4. **Your turn.** The steps to do this for a new game, as a checklist.

## How sure are we?

The robot has not been built yet, so nothing in the playbook has been tested on real parts. Every number carries one of five labels:

| Label | What it means |
| --- | --- |
| Calculated | Worked out by hand or in a script from catalogue data |
| Modelled | Measured on the CAD model: weights, clearances, clashes |
| Simulated | Run in the robot code simulator |
| Assumed | A guess that still needs measuring |
| Tested | Measured on real parts |

## How the robot was made

The robot is a practice design for REEFSCAPE, the 2025 FIRST Robotics Competition game. A Team 4206 mentor designed and coded it in the off-season, working with Claude, an AI model made by Anthropic.
